# Image asset profile

## Purpose

Inspect, validate, or create image assets for the project when the task requires image work.

## Allowed capabilities

- Read image files from project asset directories relevant to the task.
- Inspect dimensions, format, transparency, and visual appearance.
- Create or modify assets only when requested, and write them only to the project asset location agreed for the task.
- Use project-local preview or conversion tools when available and appropriate.

## Boundaries

- Do not upload project assets or user-provided images to an external service without explicit authorization.
- Do not use assets with unclear rights or provenance; record required attribution or licensing information according to project policy.
- Do not overwrite or delete existing assets unless the task explicitly calls for it.
- Do not inspect unrelated personal images or files.
