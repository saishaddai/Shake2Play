# Decision records

Use this folder for architecture and tradeoff records that should survive beyond a single patch.

## Typical entries

- target and source-set decisions
- API contract choices
- language interop decisions
- platform-specific boundary decisions
- dependency or framework selection rationale

## Format

Keep each decision short and explicit:

- Context
- Decision
- Consequences
- Alternatives considered

This directory should be small and focused on durable design intent rather than transient implementation notes.
