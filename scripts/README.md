# Scripts

This folder contains local automation and validation helpers used by the project.

## Purpose

- Provide repeatable project checks
- Simplify local validation and onboarding
- Keep commands consistent across contributors and AI-assisted workflows

## Rules

- Prefer existing build tooling before adding ad hoc scripts.
- Keep scripts version-controlled and deterministic.
- Avoid storing secrets or environment-specific values in scripts.
- Document how and when each script should be run.
